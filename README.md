One sentence explaining the modern internet to someone arriving from 1800.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Imagine a library where every book in the world shouts at once, and somehow you can order dinner from it while a stranger argues with you.
```
